## Recording integrity

Use the result actually returned. Publisher order may vary. The inability-to-stand query returned condition-preserving ICADB passages in the v31 check; do not imply a specific source must always rank first.

If email receipt has not been verified during preparation, show a saved draft and the inbox workflow, and omit any received-email shot. If a test message is sent, send only to the controlled demonstration mailbox. There is no need to reveal an administrator password or a real user's email address.

The introductory language cards are direct publisher links. Do not narrate that click as AI reasoning. Internal relevance values are not displayed and should not be animated as accuracy percentages. Do not describe the system as a substitute for qualified religious review.
